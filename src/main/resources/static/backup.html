Copias de seguridad

Respalda y restaura la base de datos MySQL.

⇩
Crear backup

El proyecto incluye un script de Windows para exportar restaurante_db mediante mysqldump.

scripts\backup_mysql.bat

Ejecuta el script desde Windows. La web no ejecuta comandos del sistema por seguridad.

↶
Restaurar backup

Utiliza el script de restauración incluido en la raíz del proyecto.

scripts\restaurar_mysql.bat
Antes de restaurar, crea una copia de la base actual para evitar pérdida accidental de información.
